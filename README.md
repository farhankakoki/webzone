# Webzone Online Service Center

Welcome to the repository for **Webzone Online Service Center**, a fast, multilingual digital service hub tailored for seamless WhatsApp-based interactions.

🌐 **Live Domain:** [https://webzonekgr.in](https://webzonekgr.in)

## 📌 Features
- **Multilingual Support:** Fully supports English, Malayalam, and Hindi to cater to all local and migrant demographics.
- **WhatsApp Integration:** "Zero Registration" system. Users request services with a single click that auto-generates a WhatsApp message.
- **Secure Admin Portal:** Manage News and Events directly from the `/admin` portal (secured via SHA-256 client-side hashing and LocalStorage).
- **Responsive & Minimalist:** A dark/light high-end UI optimized heavily for mobile devices (Mobile-First CSS Grid).
- **Local SEO Optimized:** Targeted keywords for Areekode, Kadungalloor, Kizhisseri, and surrounding regions.
- **Fast Performance:** Pure HTML/CSS/JS stack with no backend dependencies, using lazy-loading and CSS-based skeleton screens for instant perceived load times.

## 🚀 Tech Stack
- **HTML5 & Vanilla CSS3:** For robust, lightweight structuring.
- **Vanilla JavaScript (ES6+):** Handling DOM manipulation, admin logic, and translations directly in the browser.
- **FontAwesome:** For rich iconography.

## 📂 Project Structure
- `/admin/`   - Admin Portal Interface
- `/css/`     - Global Styles, Utilities, and Responsive Layouts
- `/images/`  - Assets (Logo, Favicon, Author images)
- `/js/`      - Core Logic (`app.js`, `data.js`, `translations.js`, `admin.js`)
- `index.html`- Main Client Portal

## 🛡️ Admin Access
The admin interface is accessible at `https://webzonekgr.in/admin`.
It utilizes encrypted browser-side verification for rapid, serverless CMS-like management of the "Latest Updates" feed.
